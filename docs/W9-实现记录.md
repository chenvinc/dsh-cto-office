## 一、监督器完整版：三段超时合成一个

规格要求「三个超时合成一个监督器，不各做一套」（§14.5）。现在一个 `tick()` 同时管三件事：

| 段 | 触发条件 | 报警对象 | 动作 |
|---|---|---|---|
| `queuedAlert` | `QUEUED` 卡的**持有者** idle 超阈值 | 持有者（文案里点名 C1，不是「C2 等了多久」） | `suggest-release`；超 `threshold × escalateAfter` 升级为 `suggest-abort` |
| `exclusiveTtl` | 互斥占用 idle 超阈值（M-14 第三处） | 持锁卡 | 不再阻塞别人 + 审计（`exclusive-expired`） |
| `cardIdleReclaim` | **在飞卡自己** idle 超阈值 | 该卡 | `suggest-abort` |

三条设计要点：

1. **阈值全是参数**：`queuedAlert.thresholdMs / escalateAfter`、`exclusiveTtl.thresholdMs`、
   `cardIdleReclaim.thresholdMs`。同时兼容老的扁平键（`queuedAlertMs` / `exclusiveTtlMs` / `escalateAfter`），
   老配置不会因为这次升级静默失效 —— 有测试钉住。
2. **升级是一条新报警**：去重键是 `cardId + reason + escalation`。只按 `cardId + reason` 去重的话，
   「警告升级了」永远看不见 —— 那是把最需要人看的时刻吞掉。
3. **续租是隐式的**：任何 `gate` / 回执 / `note` 都会推进 `updatedAt`，所以有活动自然不进这三条。
   没有单独的「续租」接口要人去调（少一个会忘的动作）。

`ack()` 可一次清空；`pending()` 供 `office_status` / 看板读取。

## 二、每日看板完整版：一个入口、三块

`office_dashboard(workspace)` —— **只读**，不判定、不改状态。

```
# 每日看板 2026-11-26

## ① 在飞卡（0 张）
（无）

## ② 昨日 gate 结果（2026-11-25，真实样本）
判定 0 次：PASS 0 ｜ CHANGES 0 ｜ 通过率 —
（昨日没有判定记录）

## ③ 异常信号（0 条）
（无）

## 指标（M-12）
真实样本 5 张（排除注入 0）｜阻塞率 0%｜回退率 0%｜越界率 20%
判据：数据不足（不给建议）
```

细节：

- **① 在飞卡**：state / idle 分钟 / rounds / baseSha(8 位) / blockedBy / 互斥 glob（过期标 ⚠）/ 超 reclaim 阈值标 ⚠，按 idle 降序。
- **② 昨日 gate**：按**本地日**切（人的「昨天」，不是 UTC），只统计 `sampleTag !== 'injected'` 的真实样本，
  给 PASS/CHANGES 计数、通过率、违规类型 top3。
- **③ 异常信号**：待处理报警（含 escalation）、坏卡、坏证据、互斥过期审计、在飞卡 idle 超阈值。
- **指标**：直接复用 M-12 的 `computeMetrics` —— **判据只有一处实现**，看板不另算一套阈值。

**为什么是工具而不是 GUI 面板**：client 半的面板（`client.js` liveboard）已是最小版，改它要重建产物、
且它的数据源是 liveboard 事件流（D1）。W9 的目标是「一个入口、三块」这个**节奏**，而不是换渲染位置。
所以看板先以工具形式给到 CTO 会话，`office_dashboard` 一次读完；面板维持最小版，记在这里而不是假装做了。

## 三、踩到的三个坑（都是测试自己写错）

| 现象 | 原因 | 修法 |
|---|---|---|
| `QUEUED → SETTLED` 抛 `IllegalTransitionError` | fixture 想造「已结算卡」，忘了状态机要求先 DISPATCHED | 补齐跃迁 —— 状态机是硬的，测试不能抄近道 |
| 「升级必须再响一次」断言 2 !== 1 | 同一轮里**两条**报警（holder-idle 升级 + 该卡自己 card-idle）同时触发 | 断言改成找 `holder-idle` 那条，并显式断言两件事独立 |
| 「今天的判定不算昨日」2 !== 0 | fixture 用固定日期造「昨日」，但看板用**真实 now** 比较 | 断言改按真实 now 推导 —— 这也证明「昨日按本地日算」是对的 |

## 四、有意没做

| 项 | 状态 | 理由 |
|---|---|---|
| GUI 面板完整版（三块渲染进 `client.js`） | 未做 | 见上：W9 的目标是节奏与入口；面板改动涉及客户端产物与 HMR，另议 |
| `escalate` 的自动动作（自动作废/自动释放） | 未做 | 规格是 `on_expire: auto_release + audit` 只针对互斥 TTL；**卡本身**只 `suggest-abort`，不作废活卡 |
| 报警主动推送到会话 | 做不到 | 插件没有「向会话注入消息」的服务（D 类依赖），只能落 `alerts.jsonl` + 下次工具响应里 |
